# to-do-list
simple to-do web app that you can use ass web and chrome widget

for make from this app a widget:
1. Open your browser (e.g., Google Chrome or Yandex Browser) and go to the extensions management page. Type chrome://extensions/ into the address bar (or find it through the settings menu: More tools -> Extensions).
2. In the top-right corner of the page, toggle on "Developer mode".
3. Click the "Load unpacked" button that appears on the left.
4. Select your project folder todo-extension and click OK.
Ready for work!
